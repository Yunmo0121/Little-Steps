# 🌊 Chapter 02 — The Tidal Island 使用说明

这是 Little Steps 第二季的**第二座可玩岛屿**。第一章练习寻路和奖励学习；第二章研究为什么**同一地点，在不同潮位下的正确决定可能不同**。

## 怎么开始

打开 `index.html` → 主菜单 **The Enchanted Isles** → 在 World Map 点击 **02 Tidal Island**。先阅读三页绘本剧情，也可以点 **Skip story** 直接开玩。第一章 Lantern Bay 仍然开放。

## 核心规则

- 地图是 **7 × 9** 方格。包括港口、灯塔、礁石、海水、粗糙海域和黄色沙洲。
- 潮汐每做一次动作就推进一格：**Low · ebb → Low · turning → High · rising → High · peak → 循环**。
- **黄色沙洲 T** 只有当前是低潮才能进入；如果潮位变成高潮时 Kristie 还停在沙洲上，会被浪带回起点并受到惩罚。
- 即使移动撞到礁石、或沙洲因高潮无法通过，时间仍然流逝。
- 与第一章不同，本章新增第五个真实动作 **Wait**，让 Kristie 停在安全地点等待水位变化。

## 推荐试玩顺序

1. 点击 **Take the helm**，用方向键或 WASD 操作。按 **Space** 或页面上的 **Wait** 等待一个潮汐阶段。
2. 自己试着穿过黄色沙洲。看见高潮时被封闭的路，再试走较远但始终开放的路线。
3. 切换 **Q-Learning / SARSA**，点击 **Train 200 episodes**，然后 **Train +800**。
4. 点击 **Show policy**，观察格子里学到的动作箭头；选择一个格子，在右边 **Inspect phase** 切换低潮和高潮，对比该位置五种动作的 Q 值。
5. 查看训练曲线（**Success / Reward**）和 **Follow learned route**，并与 BFS 和 Dijkstra 的时间感知基准路线比较。

## 算法与实验

状态是 `s = (position, tide_phase)`，共 `7 × 9 × 4 = 252` 种；动作五种（上、右、下、左、等待），所以每个模型的 Q 表为 `252 × 5`。

- **Q-Learning**：用下个状态的最大估计动作价值来更新当前动作价值。
- **SARSA**：用下一个实际选择的动作来更新（on-policy）。
- **BFS**：事先知道潮汐规则，在扩展后的时间状态图里寻找动作最少的解。
- **Dijkstra**：同样知道规则，但用行动努力成本规划（普通移动 1，粗糙海域 2，等待 0.65）。右侧表格展示的 *Travel cost* 只累加移动地形成本，不含等待努力成本；与其实际优化目标或 RL 奖励函数并不相同。

默认低潮起点的基准：BFS 为 **10 次动作 / 0 次等待 / 移动代价 10**；Dijkstra 为 **10 次动作 / 2 次等待 / 移动代价 8**。两者都是规划器，预先了解环境；RL 则需要通过交互学习，不一定学出最优路线。

训练曲线中的每个点聚合最近一批 **25 个 episode**；最近成功率采用最后 50 回合；**Greedy evaluation** 只是一次不探索的确定性轨迹，不等同于很多次独立评估。

## 奖励设计

- 到达灯塔：`+40`
- 合法移动：`−0.28 − 0.24 × 地形代价`
- 等待：`−0.28`
- 尝试撞礁石或高潮通行：`−2.5`
- 被高潮冲回起点：`−5.5`
- 最长一回合：`76` 次动作

本章是**全可观测、确定性的简化教学环境**，不是气象学或真实物理海潮模型；潮汐不会根据真实时间改变，只有玩家/算法执行动作时才推进。

## 存档与本地测试

Chapter 02 的训练保存到本地浏览器 `localStorage`，并且与第一季及第二季第一章独立。随机种子默认为 `42`；同样的初始模型、参数和种子下，连续训练 `200 + 800` 回合与一次训练 `1000` 回合应产生相同 Q 表。要更改种子请先重置当前模型。

可以在项目目录执行：

```bash
node tests/test_tidal_island.cjs
```

也可以运行其他 `tests/*.cjs` 回归测试。**这个 Alpha 1.4 仍是本地开发版，尚未部署 GitHub Pages。**
