# 第二季视觉统一更新（Storybook Edition · Alpha 1.1）

这次的调整以第一季绘本风格为基础：从花园的奶油白和鼠尾草绿，过渡到浅雾蓝的海岛地图。两季继续共用衬线标题、米白纸张、柔和珊瑚粉，以及同一位 Kristie 角色。

## 具体更新

- 世界地图采用原创 SVG 矢量海岸线、五座小岛、小船和罗盘。只有 Lantern Bay 可玩，其余四座仍处于规划中。
- 保留地图按钮与操作控件作为真实网页元素，不把交互控制画死在插画内。
- RL 学习实验台从深色开发者控制台改为浅色航海笔记桌，算法参数、训练结果和 Q 值仍可操作、查看。
- 游戏引擎、种子复现、BFS、Dijkstra、Q-Learning 和 SARSA 的实际实现保持不变。

## 本地运行

解压 ZIP，打开 `index.html`，在主菜单点击 **The Enchanted Isles**。不需要安装 npm 依赖。

## 设计原则

1. 画风统一，但保持研究数据清楚易读；
2. 避免每个模块都重复相同的卡片、阴影与装饰符号；
3. 插画、剧情和算法使用不同的布局语义；
4. 已完成的算法实验和未来计划明确区分。


## Alpha 1.3：第一季与第二季故事画面统一

第二季 Chapter 01 的剧情弹窗宽度与 Season One 保持一致（桌面最大 930px），采用相同的双栏结构、正文与引语字号、圆角及阴影。海港、礁石和灯塔三张绘本插画使用一致的柔和水彩/铅笔质感，Kristie 的服饰及配件与第一季相呼应。页面切换仍然由 HTML 按钮控制，图片中不包含假 UI。
